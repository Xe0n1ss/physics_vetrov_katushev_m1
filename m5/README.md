# М5 — физический маятник

Проект моделирует свободные колебания однородного тонкого стержня с жёстко закреплённым на его конце сплошным шаром. Программа рассчитывает характеристики тела по размерам и массам, численно решает уравнение движения и исследует влияние начального угла и трения на колебания. Дополнительный вариант задания не рассматривается.

Проект полностью выполнен Ветровым Иваном Витальевичем: модель, численный расчёт, интерфейс, тесты, эксперименты и документация.

- [Отчёт: модель, формулы, метод и проверки](docs/report.md)
- [Результаты численных экспериментов](docs/results.md)

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m src.main
```

В форме задаются длина и масса стержня, радиус и масса шара, коэффициент трения. После нажатия «Рассчитать» программа показывает характеристики маятника, таблицу периодов и графики угла, энергии и фазового портрета для случаев с трением и без него. Ускорение свободного падения принято равным 9,81 м/с²; набор начальных углов для эксперимента задан программой.

## Структура

| Путь | Назначение |
|---|---|
| `src/models.py` | Параметры тела, центр масс, момент инерции, энергия и уравнение движения. |
| `src/analytical.py` | Теоретические периоды и решение для малых углов с трением. |
| `src/solver.py` | Численное интегрирование, траектория и измерение периода. |
| `src/experiments.py` | Проверка введённых параметров и серия расчётов по заданию. |
| `src/gui.py` | Локальная форма, таблицы и графики. |
| `src/main.py` | Точка запуска интерфейса. |
| `tests/` | Проверки модели, теории, численного решения и формы. |
| `docs/` | Отчёт и воспроизводимые результаты. |

## Тесты

После установки зависимостей из корня репозитория:

```bash
python -m pytest -q
```

Исходные данные, ограничения, принятые допущения и способ сравнения с теорией подробно описаны в [отчёте](docs/report.md).
