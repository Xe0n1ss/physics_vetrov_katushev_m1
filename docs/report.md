# Отчёт по моделированию физического маятника

## Цель и принятая модель

Нужно исследовать свободные колебания твёрдого тела вокруг неподвижной горизонтальной оси в поле тяжести. В проекте тело состоит из однородного тонкого стержня и однородного сплошного шара, жёстко закреплённого на его нижнем конце. Ось проходит через верхний конец стержня. Центр шара находится на расстоянии `L + R` от оси, где `L` — длина стержня, `R` — радиус шара.

Движение считается плоским; тело не деформируется. Угол `θ` отсчитывается от вертикали вниз, угловая скорость `ω = dθ/dt`. Во всех экспериментах тело отпускают без начального толчка: `ω(0) = 0`. Трение моделируется моментом `−bω` в оси. Сопротивление воздуха, движение точки подвеса и случайные воздействия не учитываются. Это модель выбранного тела, а не любого произвольного маятника.

## Геометрия и уравнение движения

Обозначим массы стержня и шара через `m_r` и `m_s`, полную массу через `M`. Центр масс расположен на расстоянии `d` от оси:

```text
M = m_r + m_s
d = [m_r·L/2 + m_s·(L + R)] / M
```

Момент инерции стержня относительно его верхнего конца равен `m_r·L²/3`. Для шара сначала берётся момент относительно его центра `2m_s·R²/5`, затем добавляется перенос к оси подвеса по теореме Штейнера:

```text
I = m_r·L²/3 + 2m_s·R²/5 + m_s·(L + R)²
```

Восстанавливающий момент силы тяжести равен `−Mgd·sin θ`. Поэтому для момента инерции `I` и коэффициента трения `b` получаем:

```text
I·d²θ/dt² = −Mgd·sin θ − b·dθ/dt
```

Для численного метода это одно уравнение второго порядка записывается как система первого порядка:

```text
dθ/dt = ω
dω/dt = −(Mgd/I)·sin θ − (b/I)·ω
```

В идеальном случае `b = 0`. При `b > 0` колебания затухают. В проекте нет внешней периодической силы: и те и другие колебания свободные.

## Энергия и теоретические ориентиры

За ноль потенциальной энергии принимается нижнее положение маятника. Тогда

```text
E = Iω²/2 + Mgd·(1 − cos θ)
dE/dt = −bω²
```

При `b = 0` энергия постоянна; при положительном `b` она убывает. Второе равенство получается подстановкой уравнения движения в производную энергии. Оно позволяет проверить численный расчёт двумя способами: по разности `E(0) − E(t)` и по интегралу `∫bω²dt`.

При малых углах `sin θ ≈ θ`. Собственная круговая частота и период идеального маятника:

```text
Ω₀ = √(Mgd/I)
T₀ = 2π/Ω₀ = 2π√(I/(Mgd))
```

При больших углах эта формула уже не описывает период точно. Для отпускания без начальной скорости и без трения используется точный теоретический период

```text
T(θ₀) = 4√(I/(Mgd))·K(sin²(θ₀/2))
```

Здесь `K` — полный эллиптический интеграл первого рода. В коде он вычисляется функцией `scipy.special.ellipk`; угол для расчёта переводится из градусов в радианы. Эта формула служит независимым ориентиром для периодов, полученных из численной траектории. Разница между `T(θ₀)` и `T₀` при большой амплитуде — физический эффект, а не ошибка интегрирования.

Формула следует из сохранения энергии при `b = 0`: если маятник отпущен из положения `θ₀`, то `Iω²/2 = Mgd·(cos θ − cos θ₀)`. Время движения от нижней точки до крайнего положения составляет четверть периода. Подстановка `sin(θ/2) = sin(θ₀/2)·sin φ` преобразует интеграл времени в стандартный интеграл `K`. Это даёт аналитический тест для численного метода без использования его результата.

Для малого угла с линейным трением положим `γ = b/(2I)`. Если `γ < Ω₀`, линейная теория даёт:

```text
Ω_b = √(Ω₀² − γ²)
T_b = 2π/Ω_b
θ(t) = θ₀·exp(−γt)·[cos(Ω_b t) + (γ/Ω_b)sin(Ω_b t)]
```

Последняя формула соответствует `ω(0) = 0`; её нельзя применять для сравнения с нелинейной траекторией при больших углах без оговорки о приближении.

Для её получения в уравнении движения заменяют `sin θ` на `θ`. После деления на `I` характеристическое уравнение имеет вид `λ² + 2γλ + Ω₀² = 0`; при малом трении его корни равны `−γ ± iΩ_b`. Отсюда возникают колебательная часть с частотой `Ω_b` и множитель затухания `exp(−γt)`.

## Входные данные и ограничения

Пользователь вводит параметры тела и положительный коэффициент трения через браузерную форму. Приняты следующие границы для условной крупной лабораторной установки:

| Параметр | Допустимый диапазон |
|---|---:|
| Длина стержня `L` | `0 < L ≤ 3 м` |
| Масса стержня `m_r` | `0 < m_r ≤ 50 кг` |
| Радиус шара `R` | `0 < R ≤ 0,5 м` |
| Масса шара `m_s` | `0 < m_s ≤ 100 кг` |

Это практические границы для условной установки с высоким помещением и рассчитанной на тяжёлый подвес осью, а не предел применимости уравнения физического маятника или гарантия безопасности реальной установки. Программа также отклоняет пустые, нечисловые и бесконечные значения и результаты вычислений, выходящие за диапазон чисел с плавающей точкой. Массы и размеры должны быть строго положительными, потому что модель описывает тело из двух реально присутствующих частей.

Для исследования именно малого трения форма требует `0 < b ≤ 0,1b_кр`, где `b_кр = 2√(I·Mgd)` — граница колебательного режима в линейной модели. Порог зависит от введённых размеров и масс и вычисляется заново для каждого тела. Множитель `0,1` выбран в проекте как рабочее определение «малого» трения; само задание его не задаёт. Внутри расчёта идеальный случай с `b = 0` создаётся автоматически.

Ускорение свободного падения фиксировано: `g = 9,81 м/с²`. Программа автоматически исследует амплитуды `5°, 15°, 30°, 60°, 90°, 120°, 150°`, сопоставляет траектории с трением и без при `60°` и проверяет теорию затухания при `1°`. Верхняя граница углов не достигает `180°`: при приближении к верхнему неустойчивому положению период идеального маятника неограниченно растёт.

## Численный метод и измеряемые величины

Функция `scipy.integrate.solve_ivp` решает систему для `θ(t)` и `ω(t)` методом RK45. Он использует внутренние шаги переменной длины и контролирует ошибку по параметрам `rtol = 10⁻¹⁰`, `atol = 10⁻¹²`. Максимальный внутренний шаг ограничен значением `T₀/100`, чтобы разрешать колебания по времени. Для построения графиков решение выдаётся в 2001 равномерно расположенной точке; это не число внутренних шагов метода. RK45 не сохраняет энергию точно по построению, поэтому её отклонение проверяется отдельно.

Время моделирования выбирается автоматически: шесть периодов, взятых по большему из точного периода идеального маятника при `150°` и периода малого затухающего колебания. Такой интервал даёт несколько полных колебаний и позволяет измерить период по траектории. Если численное интегрирование не удалось, программа сообщает об ошибке.

Для измерения периода отслеживаются моменты пересечения `θ = 0` в одном направлении — при уменьшении угла. Разность двух последовательных таких моментов принимается за один полный период. Пересечения определяются механизмом событий интегратора, а не поиском ближайшей точки на графике. Энергия вычисляется после интегрирования из `θ(t)` и `ω(t)`; отдельное уравнение для энергии не интегрируется.

Относительное максимальное отклонение энергии в случае без трения определяется как

```text
δE = max_t |E(t) − E(0)| / E(0)
```

## Эксперименты, визуализация и проверки

Для семи начальных углов без трения программа сопоставляет численные периоды с точной нелинейной формулой и показывает линию малых углов `T₀`. При `60°` сравниваются угол, энергия и фазовые портреты идеальной и затухающей траекторий. Фазовый портрет строится из пар `(θ(t), ω(t))`: без трения получается почти замкнутая кривая, при трении — движение к равновесию. При `1°` численный период с трением сравнивается с `T_b`; разность конечной и начальной энергии проверяется интегралом `∫bω²dt`.

Автоматические тесты проверяют формулы центра масс и момента инерции, предельное значение точного периода при малом угле, соответствие численного периода точной теории, сохранение и убывание энергии, аналитическое решение для малого затухающего угла, ограничения ввода и работу локальной формы. Подробные условия и фактические результаты одного воспроизводимого запуска приведены в [результатах](results.md).

## Вывод и границы применимости

При росте начальной амплитуды период идеального маятника увеличивается; при малом угле он близок к `T₀`. Без трения численная энергия сохраняется с малым отклонением, а при трении монотонно убывает и согласуется с законом `dE/dt = −bω²`. Это подтверждает согласованность принятой модели, численного решения и аналитических проверок в исследованных режимах.

Модель не описывает сопротивление воздуха, нелинейное или сухое трение, упругость стержня, движение подвеса и пространственные колебания. Поэтому совпадение с расчётной теорией не следует трактовать как проверку реального экспериментального маятника без измерений.
